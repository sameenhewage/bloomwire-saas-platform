# Research — Retail / E-commerce Use Cases

Retail and e-commerce businesses use customer messaging heavily for
pre-sale and post-sale support. Representative use cases below.

## Typical conversation types

- **Pre-sale questions** — product availability, sizing, pricing, promotions.
- **Order status** — "where is my order?", tracking, delivery estimates.
- **Returns & refunds** — return eligibility, refund status, exchanges.
- **Delivery issues** — wrong/damaged items, missed deliveries.
- **Abandoned cart / follow-up** — nudges and recovery via WhatsApp.

## Operational characteristics

- **Seasonal spikes** — sales events (festive seasons, promotions).
- **Mixed sales + support** — same conversation can shift from sales to support.
- **High WhatsApp usage** — customers prefer chat over email/phone.
- **Order-context dependency** — agents need order references (kept in the
  merchant's commerce system, not duplicated into Bloomwire).

## How Bloomwire (on Chatwoot) fits

- **WhatsApp + web chat** as primary channels.
- **Sales Agent + Support Agent roles** to split pre/post-sale handling.
- **Industry preset (retail/e-commerce)** seeds labels (order, return,
  delivery), canned responses, and a setup checklist.
- **Campaign handling** for promotions, with responses routed to the inbox.

## Out of scope (V1)

- Deep storefront/commerce-platform integration (Shopify/WooCommerce sync).
- Automated order lookups inside the inbox.
- Full billing/checkout automation.
